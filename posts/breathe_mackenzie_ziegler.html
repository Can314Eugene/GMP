오늘의 팝송 영어

Breathe

Mackenzie Ziegler

네이버 블로그에 올릴 원고 그대로입니다. 위의 본문 복사를 누르면 줄바꿈까지 그대로 복사됩니다.

오늘의 곡은 Mackenzie Ziegler의 Breathe.

Mackenzie Ziegler(매켄지 지글러)가 2017년 9월 발표한 싱글로, 지치고 힘든 순간에 서로를 다독이며 “그냥 숨을 쉬라”고 말하는 노래입니다.

제목부터 이미 처방전 같죠 — 별다른 해결책 대신 그냥 숨을 한 번 쉬라는 그 한마디. 🌬️

그런데 오늘 챙겨갈 영어는 노래보다 훨씬 실용적입니다.

오늘의 목표도 늘 똑같습니다.

세 표현을 보고, 하나라도 내 문장으로 만들기.

그럼 오늘의 GMP 영어 시작합니다. ☕🎧

📌 오늘의 영어 ①

been there before

그런 적 있다, 겪어봤다

오늘 문장에서는:

I’ve been there before.

→ 나도 예전에 그런 적 있어요.

여기서 꼭 기억할 포인트는 이것입니다.

👉 have p.p. — 경험을 말할 때!

예를 들어,

I’ve been there before, so I know how you feel.

→ 나도 그런 적 있어서 네 기분을 알아요.

또,

Don’t worry, we’ve all been there before.

→ 걱정 마, 우리 모두 그런 적 있어.

💡 been there는 공감을 나타내고, been there, done that은 “해볼 만큼 해봐서 이제 질렸다”는 뉘앙스가 더해집니다.

월요일 아침, 팀원이 또 실수했다고 울상일 때 “I’ve been there before” 한마디면 잔소리보다 분위기가 먼저 풀립니다.

📌 오늘의 영어 ②

gonna be good

잘 될 거다, 괜찮아질 거다

오늘 문장에서는:

It’s all gonna be good.

→ 모두 다 괜찮아질 거예요.

여기서 꼭 기억할 포인트는 이것입니다.

👉 gonna = going to, 편한 말투에서만!

예를 들어,

Don’t stress, it’s gonna be good.

→ 스트레스 받지 마, 잘 될 거야.

또,

Trust me, everything’s gonna be good in the end.

→ 날 믿어, 결국엔 다 잘 될 거야.

💡 be gonna + 동사원형은 글말보다 대화체·가사에서 자연스럽습니다. 격식 있는 글에서는 be going to를 씁니다.

발표 직전 긴장한 동료에게 “It’s gonna be good”, 진심 한 스푼 담아 건네 보세요.

📌 오늘의 영어 ③

let it be

그냥 놔두다, 순리에 맡기다

오늘 문장에서는:

Just let it be.

→ 그냥 내버려 두어요.

여기서 꼭 기억할 포인트는 이것입니다.

👉 let + 목적어 + 동사원형!

예를 들어,

If it’s not working, just let it be.

→ 잘 안 풀리면 그냥 내버려 둬.

또,

I tried to fix everything, but sometimes you have to let it be.

→ 다 고치려고 했지만, 가끔은 그냥 놔둬야 할 때도 있어요.

💡 let it be는 있는 그대로 받아들이는 것이고, let it go는 붙잡고 있던 것을 놓아버리는 것이라 뉘앙스가 다릅니다.

퇴근길, 오늘 안 풀린 일 하나쯤은 “just let it be” 하고 접어두는 연습도 필요합니다.

한 문장으로 연결해 볼까요?

지치고 힘든 순간을 먼저 인정한 뒤 다독이고, 마지막엔 그냥 숨을 쉬라는 가장 단순한 처방을 내리는 노래예요. 공감 → 위로 → 내려놓음의 순서를 따라갑니다.

🔊 발음도 한 줄만

· been there → 비네어

· gonna → 거너

· let it → 레릿

⭐ 오늘 딱 한 표현

오늘 하나만 기억한다면 저는

let it be

을 고르겠습니다.

애써 붙잡고 있던 일일수록 잘 안 놓아지죠. 하지만 다 고쳐보려다 오히려 지치는 날도 있습니다. 그럴 땐 “I tried, but I have to let it be” 한 문장으로 오늘 하루를 정리해 보세요.
