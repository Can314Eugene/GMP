💡 go to war = (비유적으로) 심하게 다투다, 전면전을 벌이다. 가사에서는 뒤에 I don't wanna fight가 이어져요!

가사와 일치 ✓

가사 정확: Thought we had more time (가사는 주어 I 생략)
완벽해요! 👏 I thought we had ~ = "~이 있을 줄 알았어"라는 아쉬움의 표현!
💡 think → thought (과거형)을 정확히 쓰셨어요.

3

어떤 일은 인생에서 두 번 일어나요

Some things happen twice in a lifetime.
가사와 정확히 일치 ✓

가사 정확: Some things happen twice in a lifetime
완벽해요! 👏 Some things(복수)와 happen(s 없이)을 정확히 맞추셨어요!
💡 Something(단수) → happens / Some things(복수) → happen

🎉 세 문장 모두 완벽했어요! 지난번 교정 포인트(go to war, thought we had, some things)를 전부 정확히 반영하셨네요. 정말 잘하셨어요! 👏

오늘의 표현 — 클릭해서 예문 보기

go to war / don't wanna fight

심하게 다투다 / 싸우고 싶지 않다

감정 표현

I don't wanna go to war, I don't wanna fight. → 심하게 다투고 싶지 않아, 싸우고 싶지 않아.

Let's not go to war over this. → 이 일로 심하게 다투지 말자.

I'm too tired to fight. → 싸우기엔 너무 지쳤어.

💡 go to war = (비유적으로) 심하게 다투다. wanna = want to의 구어체!

I thought we had more time.

시간이 더 있을 줄 알았어요

아쉬움 표현

I thought we had more time. → 시간이 더 있을 줄 알았어.

I thought you loved me. → 날 사랑하는 줄 알았어.

We thought we'd be together forever. → 우린 영원히 함께할 줄 알았어.

💡 thought (that) we had ~ = "~이 있을 줄 알았다" (그런데 아니었다). 기대가 어긋난 아쉬움!

Some things happen twice in a lifetime.

어떤 일은 인생에서 두 번 일어나요

Some things vs Something

Some things happen twice in a lifetime. → 어떤 일은 인생에서 두 번 일어나.

Some things never change. → 어떤 것들은 절대 안 변해.

Something happened last night. → 어젯밤 무슨 일이 있었어. (단수!)

💡 Something(한 단어, 단수) → happens / Some things(두 단어, 복수) → happen
once/twice in a lifetime = 일생에 한 번/두 번!

한 번에 정리

I don't wanna go to war. → 심하게 싸우고 싶지 않아요.
I thought we had more time. → 시간이 더 있을 줄 알았어요.
Some things happen twice in a lifetime. → 어떤 일은 인생에서 두 번 일어나요.

📌 발음 포인트

🔹 some things [썸 띵즈] vs something [썸띵]
  some things = 복수 → happen (s 없이)
  something = 단수 → happens (s!)

🔹 thought [쏘트]
  th = 혀끝을 이 사이에!
  ough = "오" (gh 묵음)

🔹 salt water [솔트 워러]
  salt = "솔트" (al = 오)
  water = "워러" (미국식 t = 러)

🔹 in a lifetime [인 어 라이프타임]
  once/twice in a lifetime = 일생에 한 번/두 번
