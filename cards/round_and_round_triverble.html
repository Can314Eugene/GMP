You're so predictable — 문법·철자 모두 완벽해요! 👏
💡 predictable = 예측 가능한, 뻔한. predict(예측하다) + -able(~할 수 있는)
"네가 어떻게 할지 다 알겠어"라는 뉘앙스예요!

2

우리에게 시간이 얼마 남지 않았어요

We're running out of time.
완벽해요! ✓

We're running out of time — 완벽해요! 👏
💡 run out of ~ = ~이 다 떨어지다, 바닥나다
running out of time(시간이 떨어지다) / running out of money(돈이 떨어지다) / running out of patience(인내심이 바닥나다)

3

누구의 잘못도 아니에요

It's no ones fault. → It's no one's fault.
no ones → no one's (소유격 아포스트로피)

It's no one's fault — 거의 완벽! 작은 교정 하나예요.
⚠️ no ones(✗) → no one's(✓) — 소유격에는 아포스트로피(')가 필요해요!
💡 no one's fault = 누구의 잘못도 아닌 → "no one + 's(소유격)" = 누구의
  someone's(누군가의), everyone's(모두의)처럼 's를 붙여요!

오늘의 표현 — 클릭해서 예문 보기

You're so predictable.

당신은 너무 뻔해요 / 다 예상돼요

성격 묘사 표현

You're so predictable. → 너 너무 뻔해.

I knew you'd say that — so predictable! → 네가 그럴 줄 알았어 — 너무 뻔해!

The ending was completely predictable. → 결말이 완전히 예상됐어.

He's predictable, but I find it comforting. → 그는 뻔하지만, 난 그게 편안해.

💡 predictable = 예측 가능한, 뻔한. predict(예측하다) + -able
반대말: unpredictable(예측 불가능한). 사람·영화·결과 등에 두루 써요!

run out of time

시간이 다 떨어지다 / 시간이 부족하다

관용표현

We're running out of time. → 우리 시간이 얼마 안 남았어.

I'm running out of money. → 돈이 떨어져 가.

We've run out of milk. → 우유가 다 떨어졌어.

Don't run out of patience with me. → 나한테 인내심 잃지 마.

💡 run out of ~ = ~이 바닥나다, 다 떨어지다
시간, 돈, 음식, 인내심 등 다양하게 활용! 진행형 running out of는 "점점 떨어져 가는 중"!

It's no one's fault.

누구의 잘못도 아니에요

소유격 핵심!

It's no one's fault. → 누구의 잘못도 아니야.

It's not your fault. → 네 잘못이 아니야.

Whose fault is it? → 누구 잘못이야?

It's everyone's responsibility. → 그건 모두의 책임이야.

💡 소유격 's 규칙: no one's(누구의), someone's(누군가의), everyone's(모두의)
⚠️ 아포스트로피(') 빠지면 안 돼요! no ones(✗) → no one's(✓)

한 번에 정리
