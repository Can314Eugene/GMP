I felt the breeze.

바람을 느꼈어요

감각 표현

I felt the breeze coming off the ocean. → 바다에서 불어오는 바람을 느꼈어.

A cool breeze swept through the window. → 시원한 바람이 창문을 통해 불어왔어.

She let the breeze play with her hair. → 그녀는 바람이 머리카락을 흩날리도록 내버려 뒀어.

💡 breeze = 산들바람, 미풍. wind보다 부드럽고 상쾌한 바람! "It's a breeze" = 식은 죽 먹기야 (관용표현).

running to the beach now

지금 바다로 달려가고 있어

⚠️ beach vs bitch

I'm running to the beach now. → 지금 바다로 달려가고 있어.

Let's go to the beach this weekend. → 이번 주말에 바다 가자.

She's a real beach person — always near the ocean. → 그녀는 정말 바다를 사랑하는 사람이야 — 항상 바다 근처에 있어.

💡 beach [비이치] vs bitch [비치] — 모음 길이 차이!
beach = 긴 "이이" (iː) / bitch = 짧은 "이" (ɪ)
⚠️ 이 두 단어를 혼동하면 매우 다른 의미가 되니 조심!

It's so plain to see.

너무나도 분명해요 / 눈에 훤히 보여요

강조 표현

It's so plain to see. → 그건 너무나도 분명해요.

It's plain to see she's in love. → 그녀가 사랑에 빠진 게 눈에 훤히 보여.

It's so clear to everyone around them. → 주변 모든 사람들에게 너무나도 분명해.

It's obvious, plain and simple. → 명백해, 아주 단순하고 분명해.

💡 plain = 명백한, 뚜렷한 (= obvious, clear). plain to see = 보기에 명백한, 눈에 훤한
It's so + 형용사: It's so → It so(✗) — 's 절대 빠지면 안 돼요!

📌 발음 포인트

🔹 beach [비이치] vs bitch [비치]
  ★ 오늘의 핵심!
  beach = 해변 → ea = 길게 "이이" (iː)
  bitch = 비속어 → i = 짧게 "이" (ɪ)
  연습: bee + ch = 비이치 (벌처럼 길게!)

🔹 breeze [브리이즈]
  br- 연결 발음, ee 길게, -ze는 "즈" (목 울려서)

🔹 plain [플레인]
  ai = "에이" 이중모음 → 플레인

  It's = It is의 축약형. 's 절대 빠지면 안 돼요!
